02 / System anatomy4 blocks

Four Blocks Decide Measurement Capability

A test system is only as repeatable as its weakest block. The analyzer sets the electrical range, the matrix sets the port count, the fixture sets contact repeatability and the software sets what the line records.

Block 01

Vector network analyzer

Measurement engine for S-parameters, gain and VSWR. Frequency range, port count and sweep settings are fixed against the device specification.

Block 02

Solid-state switch matrix

Expands analyzer ports to the device. Port expansion runs from 2 to 8, 9, 16 or 32 ports over 9 kHz–8 GHz; full-matrix options cover 12 and 18 ports.

Block 03

RF test fixture

Positions the device and makes the RF and DC contacts. Pneumatic actuation, replaceable spring probes, SMA female RF interface and a two-hand start.

Block 04

Test software

Runs the sequence, applies limits, shows pass or fail by channel and records results. CSV export, label printing and line-side data upload are configured per project.

System integration is project-specific. Cycle time, repeatability and gauge capability depend on the device, fixture, switch settling, analyzer settings and accepted limits; no universal figure is published here.

Antenna Test System Questions

Five questions asked before a production test system is specified.

Can one system test a nine-port base-station antenna?

Yes, if the matrix and fixture are sized for the port map. A 16×16 or 32-port matrix covers panels with nine or more ports, and the software records each port pair. The port map, connector type and measurement sequence must be supplied before the matrix and fixture are confirmed.

Which network analyzer is used?

The analyzer is selected with the project against frequency range, port count and required measurements. The system software controls it over its remote interface. A customer-supplied analyzer can be evaluated, but compatibility and required options must be confirmed before acceptance.

Does the software upload data and print labels?

The software records pass or fail by channel and can export results as CSV. Label printing and line-side upload are configured per project against the fields the customer needs. No specific MES integration is claimed until the interface is confirmed.

Is cycle time guaranteed?

No universal cycle time is published. Cycle time depends on the device, number of measurement points, switch settling, analyzer sweep settings and fixture actuation. It is measured on the accepted configuration, not inferred from a similar system.

Can the fixture be built for a new device?

Yes. Fixtures are built from the device drawing and a sample where available. Probe selection, keying, RF interface, guarding and the start condition are confirmed before release. A fixture for one device is not assumed to fit another, even when the outline is similar.
