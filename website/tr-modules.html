02 / Module anatomy4 blocks

What Sits Inside a T/R Channel

Every channel repeats the same four blocks. The array performance is the sum of these channels, so channel-to-channel tracking matters as much as the single-channel specification.

Block 01

Transmit chain

Drives the antenna port at the rated power. Gain, saturated output and efficiency are set together with the duty cycle the array will run.

Block 02

Receive chain

Low-noise amplification ahead of the array combiner. Noise figure and gain are specified at the module output, not at the antenna.

Block 03

Phase and attenuation

Beam steering and amplitude taper are applied per channel. Resolution is 4 to 7 bits depending on the family; the control word is defined with the beam controller.

Block 04

Control and power

A single control interface carries channel settings and health data. Supply voltage, current per channel and thermal path are confirmed against the array housing.

04 / Application fit3 routes

Where These Modules Are Used

The module is the repeating element of an array. The application decides the channel pitch, the control bus and how much heat the housing must move.

Route 01

Radar front ends

Pulsed operation with tight channel tracking. Duty cycle drives the thermal case, and the module is specified against the waveform rather than a continuous rating.

Route 02

Satellite terminals

Ku and Ka bands with phase control for electronic steering. Gain and noise figure are specified at the module interface used by the terminal.

Route 03

Test and instrumentation

Multichannel sources and receivers where a compact 8- or 32-channel block replaces discrete instruments.

Route 04

Custom array builds

Channel count, pitch and control interface are re-cut for the array. A module family is a starting point, and the layout is confirmed against the housing.

Customer names and program references are not published. Applications are described by function so the engineering fit can be assessed without disclosing a customer's design.

T/R Module Questions

Five questions asked before a module layout is frozen.

Can the channel count be changed?

Yes. The published families cover 8, 13 and 32 channels, and the count follows the array lattice. Channel count changes the board layout, the control word and the thermal path, so it is fixed before the first article rather than added afterwards.

Is transmit power quoted per channel or for the module?

Per channel, at the module output. The figure depends on duty cycle, pulse width and cooling, so the sustained rating is agreed for the actual waveform. A peak number taken from another application is not a valid comparison.

Which phase and attenuation resolution is available?

Six-bit phase and six-bit attenuation on the 8-channel Ku module; 4-bit to 7-bit options on the configurable Ku family. The resolution is chosen with the beam controller so the control word and the software table match.

Do you publish environmental qualification for every module?

No. Qualification is quoted per project against the stated test standards, and the report covers the delivered configuration. A generic qualification statement would not tell you how a specific module behaves in your housing.

Can you supply the control electronics as well?

Yes, when the project needs it. The control board, interface and channel table can be supplied with the module or built to the customer's own controller. The interface definition is agreed before layout so both sides can be tested independently.
