Four Values Settle Most Matrix Projects

Frequency range, path count, isolation and power handling are coupled. Raising one usually moves the others, so they are reviewed together rather than quoted one at a time.

Lever 01

Frequency range

The band sets switch type, connector series and path layout. Wideband coverage to 18 GHz is available, but loss and isolation are specified at defined points, not as one flat figure.

Lever 02

Path count and topology

Fan-out accepts one common port and many branches. A full matrix needs a crosspoint at every intersection, so cost and loss rise faster than the port count.

Lever 03

Isolation

Isolation decides whether an unselected path can disturb the measurement. Published values range from 60 dB to 70 dB depending on configuration and band.

Lever 04

Power and control

Solid-state switches suit low-level measurement paths; the 8×8 configuration is rated to 20 dBm. Control is by the test software over the interface agreed at review.

Where a project needs higher power than a solid-state path allows, a different switch technology or a relay-based design is reviewed instead. That decision is made before the enclosure and control board are released.

03 / Signal path5 nodes

From Instrument Port to Device Under Test

The signal path is short by design. Every added node contributes loss, mismatch and a calibration step, so the chain is drawn before the hardware is built.

  1. Instrument portThe analyzer or source connects at the common port. Port count and connector series are confirmed against the instrument.
  2. Input routingInternal cabling and the first switch stage set the loss floor. Cable lengths are matched where phase matters.
  3. Switch coreSolid-state switches select the path. Switching time, isolation and power rating are properties of this stage.
  4. Output fieldOutputs land on a labelled connector field — A1–A8 and B1–B8 on the 8×8 unit — so the port map is readable at the rack.
  5. Control and calibrationThe control interface is driven by the test software. Path loss and phase are characterized during integration so limits can be set per path.

What the Integration Review Covers

A matrix is rarely bought alone. It is accepted as part of a measurement chain, and the chain is what determines whether the published isolation still holds at the device.

Switch Matrix Questions

Five questions asked before a routing configuration is fixed.

Fan-out or full matrix — which one do I need?

Use fan-out when one instrument must reach many test points in sequence. Use a full matrix when any port must be measured against any other, as with multi-port antennas or multichannel modules. A full matrix needs a crosspoint at every intersection, so loss and cost rise faster than the port count.

Can the matrix extend my existing analyzer?

Yes. Port expansion from two ports to 4, 8, 9, 16 or 32 ports is available over 9 kHz–8 GHz; the configurations are ES5204, ES5208, ES5209, ES5216 and ES5232. The analyzer model, its remote interface and the connector series are confirmed before the matrix is built, because the control software must drive both.

How is isolation specified across the band?

Isolation is specified at defined frequencies for each configuration, not as one flat number across the whole band. Published values range from 60 dB to 70 dB. The value that matters is the one at the frequencies where the device is actually measured.

Is the switch matrix calibrated?

Path loss and phase are characterized during integration, and the correction is applied by the test software. The calibration method is documented so the customer can repeat it. A standalone matrix is delivered with its measured path data, not with a permanent internal correction that cannot be verified.

Can the port labels follow our own naming?

Yes. The front-panel field is labelled to the customer port map — A1–A8 and B1–B8 on the 8×8 unit are one example, not a fixed scheme. The labels, the software channel names and the record fields are aligned so an operator reads the same name at the rack and in the report.
